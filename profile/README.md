### AICostBudget

We keep AI API prices in one place, each one linked to the provider's own pricing page and dated, so you don't have to scrape ten pricing pages to answer "what will this cost?".

| Repository | What it is |
| --- | --- |
| [ai-api-pricing-data](https://github.com/aicostbudget/ai-api-pricing-data) | LLM and AI API prices as JSON, CSV and a free static API, with price history. Also on [npm](https://www.npmjs.com/package/ai-api-pricing), as an MCP server (`npx -y ai-api-pricing-mcp`) and on [Hugging Face](https://huggingface.co/datasets/aicostbudget-ai/ai-api-pricing). |
| [llm-cost-per-task-benchmark](https://github.com/aicostbudget/llm-cost-per-task-benchmark) | What one correct answer really costs: 16 tasks, code-only validators, bring your own API keys. |

Tools built on the same data: [model price comparison](https://aicostbudget.com/en/model-pricing-comparison?utm_source=github&utm_medium=referral&utm_campaign=org_profile&utm_content=comparison) · [API cost calculator](https://aicostbudget.com/en/ai-api-cost-calculator?utm_source=github&utm_medium=referral&utm_campaign=org_profile&utm_content=calculator) · [price change monitor](https://aicostbudget.com/en/model-price-monitor?utm_source=github&utm_medium=referral&utm_campaign=org_profile&utm_content=price_monitor)

Found a wrong or outdated price? [Open an issue](https://github.com/aicostbudget/ai-api-pricing-data/issues) with the official source link.
